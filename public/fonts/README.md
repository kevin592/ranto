# 自托管字体

来源：Fontsource 官方 npm 包 5.3.0，获取于 2026-09-05。字体文件保留原始内容，仅调整文件名；许可均为 SIL Open Font License 1.1，完整许可随文件保留。

- `manrope-latin-variable.woff2`：`@fontsource-variable/manrope` 的 Latin / normal / wght 子集，网站使用 400–800 字重。作者：The Manrope Project Authors。来源：https://fontsource.org/fonts/manrope 。许可：`Manrope-OFL.txt`。
- `noto-sans-thai-variable.woff2`：`@fontsource-variable/noto-sans-thai` 的 Thai / normal / wght 子集，网站使用 400–700 字重。作者：The Noto Project Authors。来源：https://fontsource.org/fonts/noto-sans-thai 。许可：`Noto-Sans-Thai-OFL.txt`。

CSS family 名分别为 `Manrope` 与 `Noto Sans Thai`。泰语字体仅在匹配泰语字符时加载；拉丁字符由 Manrope 显示，中文和日文使用系统无衬线字体回退。
